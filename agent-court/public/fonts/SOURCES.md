# Bundled typography

Satoshi by Indian Type Foundry, obtained from the official Fontshare CSS API on 2026-10-05. Weights 400, 500, 700 and 900 are unmodified WOFF2 files.

- Typeface: https://www.fontshare.com/fonts/satoshi
- Distribution endpoint: https://api.fontshare.com/v2/css?f[]=satoshi@400,500,700,900&display=swap
- License source: https://www.fontshare.com/licenses/itf-ffl (Indian Type Foundry Free Font License)
- Official download: https://api.fontshare.com/v2/fonts/download/satoshi
- Exact unmodified FFL 2.0 (2026-08-17) from that ZIP: `Satoshi-FFL.txt`. It permits self-hosting for the licensee's own website but restricts font redistribution, including through repositories. Obtain font binaries directly from Fontshare when setting up this project.

IBM Plex Mono, unmodified weights 400 and 500, obtained from Google Fonts' official distribution. The IBM upstream SIL Open Font License is included in `IBM-Plex-LICENSE.txt`.

- Typeface source: https://github.com/IBM/plex
- Distribution: https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500&display=swap
- License: https://raw.githubusercontent.com/IBM/plex/master/LICENSE.txt

All rendered fonts are served locally from `/fonts/`; the website does not fetch font assets from external services at runtime.
